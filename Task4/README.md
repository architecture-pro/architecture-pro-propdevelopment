| Роль               | Права роли                                                                                                                | Группы пользователей        |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| `cluster-viewer`   | Просмотр Pods, Services, Deployments, Nodes и Namespaces во всём кластере (`get`, `list`, `watch`). Без доступа к Secret. | Сотрудники мониторинга      |
| `cluster-operator` | Просмотр, создание, изменение и удаление Pods, Services и Deployments в namespace `default`. Без доступа к Secret.        | Инженеры сопровождения      |
| `secret-manager`   | Просмотр, создание, изменение и удаление Secret в namespace `default`.                                                    | Администраторы безопасности |
