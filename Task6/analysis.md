# Отчёт по результатам анализа Kubernetes Audit Log

## Подозрительные события

### 1. Доступ к секретам

- **Кто:** `minikube-user` от имени `system:serviceaccount:secure-ops:monitoring`.
- **Действие:** попытка получить список Secrets в namespace `kube-system`.
- **Результат:** `403 Forbidden`. Доступ запрещён политикой RBAC.
- **Риск:** возможная утечка конфиденциальных данных при получении доступа к Secrets.

### 2. Создание привилегированного Pod

- **Кто:** `minikube-user`.
- **Действие:** создание `privileged-pod` в namespace `secure-ops` с параметром `privileged: true`.
- **Результат:** Pod успешно создан (`201`), но находился в состоянии `Pending`.
- **Риск:** привилегированный контейнер при запуске может получить расширенный доступ к ресурсам узла.

### 3. Использование kubectl exec

- **Кто:** `minikube-user` по сценарию симуляции.
- **Действие:** попытка выполнить команду в Pod CoreDNS в namespace `kube-system`.
- **Результат:** команда завершилась ошибкой, так как Pod не был найден. Событий `pods/exec` в журнале нет.
- **Риск:** выполнение команд в чужих Pod может привести к несанкционированному доступу.

### 4. Создание RoleBinding с правами cluster-admin

- **Кто:** `minikube-user`.
- **Действие:** создание `escalate-binding` в namespace `secure-ops`. По скрипту RoleBinding связывает ServiceAccount `monitoring` с ClusterRole `cluster-admin`.
- **Результат:** RoleBinding успешно создан (`201`). В журнале зафиксировано создание, но содержимое RoleBinding отсутствует из-за уровня аудита `Metadata`.
- **Риск:** предоставление избыточных административных прав ServiceAccount в пределах namespace.

### 5. Удаление audit-policy.yaml

- **Кто:** в скрипте указан пользователь `admin` через `--as=admin`.
- **Действие:** попытка удалить `audit-policy.yaml`.
- **Результат:** команда завершилась ошибкой из-за отсутствия файла по указанному пути. Событие удаления в журнале не найдено.
- **Риск:** отключение аудита могло бы скрыть последующие действия в кластере.

## Вывод

По результатам анализа выявлены следующие события:

- Попытка доступа к Secrets заблокирована RBAC.
- Привилегированный Pod успешно создан, но его запуск не подтверждён.
- Попытка `kubectl exec` не выполнена.
- RoleBinding с избыточными правами успешно создан.
- Удаление политики аудита не выполнено.
