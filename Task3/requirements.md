# Задание 3. Внешние интеграции

## 3.1. Требования к безопасности

- Защита передачи данных между PropDevelopment и платформой партнёра
- Проверка прав доступа перед открытием домофона и шлагбаума
- Защита биометрических данных и автомобильных номеров
- Разграничение прав пользователей и возможность отзыва доступа
- Журналирование событий доступа и выполненных команд

## 3.2. Аутентификация и авторизация

- **Keycloak** — существующий сервис аутентификации пользователей
- **OpenID Connect / OAuth 2.0** — предлагаемые протоколы аутентификации и авторизации
- **HTTPS/TLS** — защищённое взаимодействие с платформой партнёра
- **Проверка разрешений** — доступ предоставляется только авторизованным пользователям

## 3.3. Взаимодействие систем

Предлагается использовать существующее мобильное приложение и `tenant-core-app`

1. Пользователь отправляет команду через мобильное приложение
2. `tenant-core-app` проверяет права доступа
3. `smart-home-integration` передаёт запрос платформе партнёра через API
4. Платформа управляет домофоном или шлагбаумом
5. Результат выполнения возвращается в приложение

Автоматическое открытие выполняется после распознавания лица или автомобильного номера и проверки разрешения

Для передачи событий звонка и результатов команд предлагается использовать HTTPS webhooks
